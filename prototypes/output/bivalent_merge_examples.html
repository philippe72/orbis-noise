Bivalent merge + linear referencing — before/after examples

Question (issues #8, #15): does merging Orbis road ways across bivalent nodes, with tags re-expressed as linear references and way-relative values re-based into merged-road space, preserve all information while erasing sectioning? Each example shows the same road before (as stored: many ways, one value per way) and after (canonical: one merged road, offset-based attribution). Circles = bivalent join nodes erased by the merge; squares = real endpoints (junctions/dead ends). Hover any block for exact values.

Clip: data/clips/amersfoort_26340.osm.pbf — generated by prototypes/bivalent_merge_prototype.py (throwaway prototype)
